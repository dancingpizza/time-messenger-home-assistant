# Verification — идентичность Time / Syncer

Дата проверки: 2026-08-11  
Режим: fresh-context verifier, normal validation  
Объём: spot-check ключевых утверждений из `official-docs-r1-1.md` и `official-docs-r2-1.md`; 6 публичных источников. Пользовательский контекст использован только для постановки вопроса и не засчитан как внешнее доказательство.

## Итог

Надёжно подтверждается узкая цепочка **Time → ООО «ТЦР»**: ТЦР на странице домена T‑Bank заявляет исключительное право на «Корпоративный мессенджер Time», а каталог АРПП повторяет вендора ТЦР и запись реестра № 28364. Публично наблюдаемы документация API v4/v5, указание на сторонние приложения и коммерческое предложение SaaS/on-premise.

Надёжно подтверждается и отдельная публичная идентичность **Syncer → Arctera AM** в RuStore. Однако просмотренные источники не устанавливают, что Syncer является мобильным клиентом сервера Time, переименованием Time, форком, лицензированной или white-label-сборкой. Такое отношение остаётся **unverified**. Разные Android package ID доказывают только отдельные поставки/листинги, а не независимость или общность кодовой базы.

## Проверенные утверждения

### 1. Time связан с Т‑Банком / ТЦР

- **Outcome: verified. Confidence: high.**
- Официальная страница ТЦР на домене T‑Bank называет полное юридическое лицо ООО «ТЦР» и заявляет его исключительное право на «Корпоративный мессенджер Time», реестровая запись № 28364 от 06.06.2025.
- Каталог АРПП независимо по издателю показывает продукт «Корпоративный мессенджер Time», вендора ТЦР и тот же номер реестра. Семантически он поддерживает идентификацию продукта и вендора, но, вероятно, использует данные государственного реестра, поэтому это не полностью независимое первичное основание.
- **Коррекция:** корректно писать «правообладатель/вендор Time — ООО „ТЦР“, компания из контура T‑Bank». Формулировка «правообладатель — Т‑Банк» без уточнения юридического лица была бы слишком широкой.
- Источники: [ООО «ТЦР»: информация о компании](https://www.tbank.ru/software/tcr/company-info/), [каталог АРПП](https://catalog.arppsoft.ru/product/6425017).

### 2. У Time есть публичные документы, API и SaaS/on-premise предложение

- **Outcome: verified для наличия публичных страниц и заявленного предложения; unverified для фактической работоспособности в tenant. Confidence: high / medium соответственно.**
- Публичная страница API прямо говорит, что API веб-сервисов Time используется клиентами Time и сторонними приложениями; навигация показывает ветки v4 и v5 и cookbook. Это семантически подтверждает публичность документации и заявленное назначение API.
- Коммерческий сайт публично показывает ссылки на API, развертывание, администрирование и интеграции, заявляет интеграции через API/Webhook/плагины и предлагает SaaS и размещение на инфраструктуре клиента.
- **Коррекция:** эти страницы доказывают, что вендор документирует и предлагает функции, но не доказывают без тестового tenant доступность всех endpoint-ов, выдачу токенов или фактическую совместимость внешней интеграции. Независимой эксплуатационной проверки в лимите источников нет.
- **Drift подтверждён:** на одной странице тарифный блок указывает SaaS от 50 и on-premise от 500 лицензий, а FAQ — SaaS от 100 и on-premise минимум от 1 000. Конкретные минимумы следует считать disputed до письменного ответа продавца.
- Источники: [введение API v4](https://docs.time-messenger.ru/api/v4/%D0%B2%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5/), [официальный сайт Time](https://time-messenger.ru/).

### 3. «Syncer — мобильный клиент» и возможная связь с Time

- **Outcome: verified только в узком смысле мобильного Android-приложения. Confidence: high.** RuStore содержит устанавливаемую карточку Syncer, категорию «Общение», разработчика Arctera AM, Android 9+ и версию 2.7 от 02.07.2026.
- **Outcome: unverified, если утверждение означает «Syncer — мобильный клиент сервера/продукта Time». Confidence: low.** Ни RuStore, ни проверенные официальные страницы Time/ТЦР такого отношения не заявляют. Пользовательское описание не является внешним доказательством.
- **Outcome: unverified для любой модели происхождения** — rename, форк, лицензирование, white-label или общая кодовая база. Confidence: low. Почти совпадающий набор функций и структура описаний Time и Syncer — содержательный lead, но семантически это доказывает лишь сходство продуктового текста/позиционирования.
- **Коррекция:** утверждение «публичного доказательства связи не найдено» допустимо только как результат ограниченной проверки шести источников, а не как доказанный универсальный факт об отсутствии документа. Уверенность в отсутствии связи должна оставаться low/medium.
- Источники: [RuStore: Syncer](https://www.rustore.ru/catalog/app/com.messenger.corp.syncer.app), [Google Play: Time](https://play.google.com/store/apps/details?id=ru.corporate.messenger.app&hl=ru), а также официальные страницы ТЦР/Time выше.

### 4. Отдельные Android packages и публичные издательские идентичности

- **Outcome: verified для разных package ID и разных storefront identities. Confidence: high.** URL карточки Time содержит `ru.corporate.messenger.app`; URL Syncer — `com.messenger.corp.syncer.app`. Это отдельные Android application IDs и отдельные карточки.
- RuStore показывает Syncer с разработчиком **Arctera AM** и адресом поддержки `info@arctera.am`.
- Google Play показывает бренд/ссылку разработчика **Corporate Messenger Time**, но в раскрытом блоке «О разработчике» указан **Дмитрий Алексеев**, email `corporate.messenger.time@gmail.com`, Russia.
- **Outcome: disputed для формулировки «издатель Time в Google Play — ТЦР». Confidence: high.** Проверенная карточка Google Play этого не говорит. Связь самого продукта Time с ТЦР подтверждается отдельными источниками, но её нельзя переносить на identity аккаунта Google Play без дополнительного документа.
- **Коррекция:** вместо «разные издатели — Corporate Messenger Time/Россия и Arctera AM/Армения» безопаснее писать «разные package ID и разные публичные developer/store identities: Time — Corporate Messenger Time / Дмитрий Алексеев (Russia), Syncer — Arctera AM». Страна Arctera/Армения не подтверждалась выбранной карточкой RuStore.
- Источники: [Google Play: Time](https://play.google.com/store/apps/details?id=ru.corporate.messenger.app&hl=ru), [RuStore: Syncer](https://www.rustore.ru/catalog/app/com.messenger.corp.syncer.app).

### 5. Что именно доказывают разные package ID

- **Outcome: verified. Confidence: high.** Разные IDs исключают простой сценарий rename-in-place одной Android-карточки.
- **Outcome: unverified для вывода о разных кодовых базах или серверах. Confidence: low.** Android application ID не раскрывает происхождение кода, backend endpoints, совместимость протокола или договорные отношения.
- **Коррекция:** во всех дальнейших выводах использовать термин «отдельные мобильные поставки/листинги», не «отдельные продукты» без дополнительного доказательства.

## Рекомендуемая формулировка для основного исследования

> Time — корпоративный мессенджер, исключительное право на который публично заявляет ООО «ТЦР»; у продукта есть публичная документация API и SaaS/on-premise предложение. Syncer отдельно распространяется Arctera AM и имеет другой Android application ID. Проверенные публичные источники не устанавливают отношение Syncer к Time, поэтому считать Syncer клиентом, переименованием, форком или white-label Time без подтверждения владельцев либо технического теста нельзя.
