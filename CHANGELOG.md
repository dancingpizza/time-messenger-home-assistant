# История изменений

## [0.0.2] - 2026-08-11

- README стал короче и проще.
- Оставлен один готовый пример автоматизации.
- Убраны внутренние термины и инструкции для разработчиков.

## [0.0.1] - 2026-08-11

- Первый выпуск для HACS.
- Добавлена поддержка новых личных сообщений из Time Messenger.
- Интеграция создает события `time_messenger_event` в Home Assistant.
- Доступны OAuth, персональный токен и вход по логину и паролю.

### Ограничения

- Групповые чаты пока не поддерживаются.
- Сообщения, полученные во время отключения Home Assistant, не восстанавливаются.
