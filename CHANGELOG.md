# История изменений

## [0.0.5] - 2026-08-13

- Добавлена страница проекта на GitHub Pages со стилизованным описанием
  возможностей и быстрым стартом.
- Обновлена фирменная иконка интеграции.
- Описание и темы репозитория на GitHub обновлены для лучшей находимости.

## [0.0.4] - 2026-08-13

- Подключение аккаунта: адрес сервера и способ входа теперь выбираются
  через привычные списки Home Assistant, а не текстовые поля.
- Форма подключения больше не теряет введённые данные при ошибке.
- Если для сервера не настроены OAuth application credentials, форма
  объясняет это прямо на месте, а не общей ошибкой подключения.
- Поля персонального токена и пароля скрыты как пароль, с подсказками
  автозаполнения.
- README переписан дружелюбнее и понятнее, добавлен пример автоматизации
  с колонкой Алисы.

## [0.0.3] - 2026-08-12

- Добавлена нативная сущность события «Личное сообщение».
- Новое сообщение теперь можно выбрать в визуальном редакторе автоматизаций.
- Событие `time_messenger_event` сохранено для совместимости.
- README обновлён: добавлены настройка через интерфейс и новый пример автоматизации.

## [0.0.2] - 2026-08-11

- README стал короче и проще.
- Оставлен один готовый пример автоматизации.
- Убраны внутренние термины и инструкции для разработчиков.

## [0.0.1] - 2026-08-11

- Первый выпуск для HACS.
- Добавлена поддержка новых личных сообщений из Time Messenger.
- Интеграция создает события `time_messenger_event` в Home Assistant.
- Доступны OAuth, персональный токен и вход по логину и паролю.

### Ограничения

- Групповые чаты пока не поддерживаются.
- Сообщения, полученные во время отключения Home Assistant, не восстанавливаются.
