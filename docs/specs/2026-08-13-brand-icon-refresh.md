# Спека: обновление брендовой иконки

Статус: реализовано (`0.0.5`). Отменяет одно требование из
[2026-08-11-hacs-packaging.md](2026-08-11-hacs-packaging.md) (repository
contract, строка про `brand/icon.png`); остальной контракт этого документа
не меняет.

## Зачем

Прежняя нейтральная синяя иконка была осознанным выбором — избежать
визуального сходства с брендом Time (Т-Банк), пока у проекта не было
публичной презентации. С запуском GitHub Pages лендинга и SEO-описания
репозитория нейтральность перестала быть приоритетом: владелец репозитория
явно решил, что иконка должна быть узнаваема как «про Time Messenger», даже
ценой визуального сходства с официальным приложением.

## Решение

- Заменена иконка во всех трёх местах, где она хранится в репозитории:
  `brand/icon.png` (мастер-ассет), `custom_components/time_messenger/brand/icon.png`
  (иконка, которую видит HACS и Home Assistant), `docs/icon.png` (favicon и
  hero-изображение GitHub Pages лендинга).
- Новая иконка — тёплая жёлто-золотая палитра и тёмный глиф (bubble + дом),
  сознательно близкая по стилю к официальной иконке Time Messenger, а не
  нейтральная замена без отсылок к бренду.
- Требование «без логотипов или товарных знаков Time/Т-Банка» из
  `2026-08-11-hacs-packaging.md` явно отменено этим решением, начиная с
  версии `0.0.5`. Это осознанный риск, принятый владельцем репозитория в
  чате при обсуждении иконки, не техническая случайность.
- Диcклеймер «неофициальная интеграция, не связана с Time Messenger /
  Т-Банк напрямую» в README и на лендинге остаётся без изменений — сходство
  иконки не подразумевает официальную аффилиацию.

## Constraints

- Иконка остаётся квадратной PNG ≥256px (проверяется
  `tests/components/time_messenger/test_documentation.py::test_repository_icon_is_a_valid_square_png`).
- Три копии иконки не связаны символической ссылкой и не генерируются
  автоматически; при следующем обновлении иконки менять все три файла в
  одном коммите.

## Non-goals

- Заявка на официальное партнёрство или листинг от имени Time/Т-Банка —
  не рассматривается, дисклеймер в README остаётся в силе.
- Юридическая экспертиза товарных знаков — решение принято владельцем
  репозитория без консультации с юристом, риск на его стороне.
